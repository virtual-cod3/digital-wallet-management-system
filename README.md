# Digital Wallet Management System

A web-based digital wallet application developed using Java and Spring Boot. It allows users to manage wallet transactions, including deposits, withdrawals, and money transfers.

## Live Demo

**[Open Digital Wallet Management System](https://digital-wallet-management-system-13v0.onrender.com)**

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript
- JWT Authentication
- Maven

## Features

- User Registration and Login
- JWT-based Authentication
- View Wallet Balance
- Deposit Money
- Withdraw Money
- Transfer Money Between Wallets
- View Transaction History
- Input Validation and Error Handling

## Project Architecture

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot, REST APIs
- **Database:** MySQL
- **ORM:** Spring Data JPA and Hibernate
- **Authentication:** JSON Web Token (JWT)

## Running the Project Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/virtual-cod3/digital-wallet-management-system.git
   ```
2. Open the project in Eclipse or another Java IDE.
3. Configure your MySQL database and environment variables.
4. Run the Spring Boot application.
5. Open the application in your browser at `http://localhost:8080`.

## Note

This project was developed for learning and demonstration purposes. It is not intended for handling real financial transactions.
